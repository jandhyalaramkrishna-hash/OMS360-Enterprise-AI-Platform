# OMS360 Enterprise AI Platform

Enterprise-grade Omnichannel Order Management System (OMS360) designed for QA Engineers and Software Testers.

The project demonstrates enterprise backend testing, API validation, database verification, event-driven architecture, and AI-assisted services using modern technologies.

---

## Features

- Enterprise Order Management System
- REST APIs using FastAPI
- Apache Kafka Event Processing
- MySQL Database
- Docker Containerization
- AI Copilot Modules
- SQL Validation
- Playwright API & UI Automation
- Manual Testing Artifacts
- Dashboard Monitoring
- End-to-End Business Workflow Testing

## Quick Start

1. Start Docker Desktop.
2. Run:

```
START_OMS360.bat
```

3. Verify:

- Swagger UI
- Dashboard
- API Health
- Kafka
- MySQL

4. Stop the application:

```
STOP_OMS360.bat
```

Detailed startup instructions are available in:

```
START_OMS360_PROJECT.txt
```
