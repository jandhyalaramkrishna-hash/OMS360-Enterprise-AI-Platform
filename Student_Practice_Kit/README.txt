WHAT'S IN THIS FOLDER
------------------------------
  OMS360 Enterprise AI Platform.exe   - double-click this to start
  docs\                                - Student Guide, API Guide, starter
                                          test cases, defect report template
  sample-data\                         - ready-to-use API request examples
  license\                             - what your license key means
  reports\, logs\                      - empty folders for your own notes

OMS360 License Generator.exe is NOT included in this folder - it is an
internal tool kept by your instructor / ZelQA Technologies staff.


HOW TO GENERATE A LICENSE KEY
------------------------------
(For instructors / ZelQA Technologies staff only - uses the separate
internal License Generator tool, not included in this student package.)

1. Run "OMS360 License Generator.exe" (kept by staff, separately from
   this folder).
2. Enter the student's name.
3. Click "Generate License Key".
4. A unique license key will appear and is copied to your clipboard.
   Send this key to the student.

Each key is valid for exactly 7 days, starting from the moment the
student activates it - not from the moment it was generated.


HOW TO START THE APPLICATION
------------------------------
(For students.)

1. Double-click "OMS360 Enterprise AI Platform.exe".
2. A branded splash window shows startup progress.
3. The first time you run it, you will be asked to enter a License Key.
   Paste the key exactly as given to you by your instructor, then click
   "Activate".
4. The application starts automatically - no other software needs to
   be installed first (no Docker, MySQL, Kafka, or Python required). Your
   browser opens to the application once it is ready.
5. A status window stays open while the app runs, showing your license
   status ("Licensed Student", "Evaluation Period", "Days Remaining") and
   an "About" button with version information.
6. On every later launch, you will NOT be asked for a key again unless
   your evaluation period has ended.

For a full walkthrough, see docs\STUDENT_GUIDE.md. For the API reference,
see docs\API_GUIDE.md. For practice test cases, see docs\TEST_CASES.md.


EVALUATION PERIOD
------------------------------
Every license is valid for exactly 7 days from the moment you first
activate it. After 7 days, the application will display:

    Evaluation Expired.
    Please contact ZelQA Technologies.

and will close. Contact your instructor or ZelQA Technologies for
further access.
